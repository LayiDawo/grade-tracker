# Grade Tracker

A small Python library and command-line demo for recording students, their scores,
and calculating averages, letter grades and class reports.

- Language: Python 3.12
- Tests: pytest, with coverage from pytest-cov

Run the tests:

```bash
pip install -r requirements.txt
pytest --cov=app --cov-report=term
```

Run the demo:

```bash
python -m app.main
```
